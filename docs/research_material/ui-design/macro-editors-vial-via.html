Vial and VIA macro editors

Redrawn from their source code, not screenshots. The same example macros in both.

Vial (vial-gui, a Vial protocol 6 board)

  • Macros is a tab of its own; the board is not drawn. Tabs M0 to M15 across the top, marked * while unsaved.
  • One row per step: ▲▼ move it, the combo sets its kind (Text, Down, Up, Tap, Delay (ms)), × removes it.
  • A Tap, Down or Up row holds one or more keys, each a small keycap; clicking one opens the keycode palette at the bottom of the window, + adds a key. Tap Tab, Tab taps them one after the other, not together.
  • On Vial 5 and later a key can be any keycode, like LCtl (Z) in M3, stored in 4 bytes.
  • Add action adds a Text row, Tap Enter a Tap Enter row. Record macro (Windows and Linux only) captures the computer's keyboard, appended or replacing. Open Text Editor... shows the macro as JSON.
  • Nothing reaches the board until Save, which writes every macro; Revert drops the changes. The memory counts all macros together and turns red when over.

VIA (the VIA web app, a VIA protocol 12 board)

  • Macros is one of the Configure menus; the board stays drawn above but cannot be clicked here. M0 to M15 in a column.
  • Two views, by the two tabs: recorded (clapperboard) and script (code).
  • The recorded view cannot add a step by hand. It shows what is stored (text in grey boxes, a pressed key outlined, a key held down with ▼ below and released with ▲ above, waits as number fields), lets one delete a step or change a wait, and records, only in full screen. Its toggles choose whether recording keeps the delays and tidies the result.
  • The script view is one line of text: {KC_ENT} taps, {KC_LGUI,KC_R} is a chord (all down, then up in reverse), {+KC_LALT} / {-KC_LALT} down / up, {300} waits; typing ? searches keycodes. Basic keycodes only.
  • Save writes the macro at once. The memory is a bar; hovering it gives the bytes.
  • VIA's labels come from QMK's key names: the Windows key reads Cmd, letters are lower case.
